## Contexte rapide

**Sihriya** est un mod de magie Forge 1.20.1 pour Minecraft. Il était indépendant avec une intégration optionnelle d'Epic Fight et STAT Mod. **On le refait en addon profond** :

- **Epic Fight** (20.14.17) → **obligatoire** — animations uniques par sort, système de combat
- **STAT Mod** (sibling `../STAT_MOD/`) → **obligatoire** — 23 stats RPG, mana via MANA_POOL, perks, XP

## STAT Mod est dans `../STAT_MOD/`

Son API est accessible directement après compilation :
- `tong.statmod.capability.PlayerStatsProvider.PLAYER_STATS` → les 23 stats
- `tong.statmod.stats.StatType` → enum des stats (FIRE_AFFINITY=10, WATER_AFFINITY=8, etc.)
- `tong.statmod.stats.StatCalculator` → formules de calcul
- `tong.statmod.perks.Perk` / `PerkManager` / `PerkProvider` → système de perks
