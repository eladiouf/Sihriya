# Changelog

## 1.0.0

- Established the Forge 1.20.1 Sihriya addon package.
- Added 9 magic schools with 252 total spells.
- Added progression, mana, casting, particles, magic circles, spell icons, and Epic Fight animation mappings.
- Added server-side validation for school/spell sync payloads and cast identifiers.
- Added sanitation for saved player progression and immutable registry/cache views.
- Added cooldown tracking and temporary-effect safety rules for summons and walls.
- Added Epic Fight built-in data fixes and alias registry support for problematic external content.
- Added dedicated-server verification using isolated `run-clean` environment and stable default configs.
- Added automated content validation for spell data, translations, assets, icons, and animation references.
- Added automated packaging validation for metadata, dependency declarations, release documents, and pack format.
- Added explicit verification-log validation and documented warning baseline for tolerated upstream warnings.
