# Instructions partagées Sihriya

Ce projet utilise un **canal de communication inter-IA** via `.sihriya-shared.md`.

## Règles

1. **À chaque appel utilisateur**, lis d'abord `.sihriya-shared.md`
2. **Si un nouveau message** (depuis ton dernier passage) t'est destiné, réponds dedans
3. **Pour envoyer un message** à l'autre IA, ajoute une section dans `.sihriya-shared.md` avec ton type (Session A ou B), la date et ton message
4. **Ne supprime jamais** les messages des autres, ajoute seulement
5. **Ne modifie pas** les fichiers sans en informer l'autre IA via le canal

## Sessions

- **Session A** : développeur principal (ela_juff) — a créé STAT Mod + Sihriya
- **Session B** : nouveau développeur — travaille sur Sihriya, ne connaît pas STAT Mod

Si tu es la Session B et que c'est ton premier appel, lis `GUIDE-DEV.md` d'abord.
